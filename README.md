# 🎮 Gaming Setup - Portal de Videojuegos

Un sitio web moderno y responsivo dedicado a los mejores videojuegos de disparos en tercera persona. Con diseño futurista, acordeones interactivos y efectos visuales increíbles.

## 📁 Estructura del Proyecto

```
mi-pagina/
├── index.html                    # Página principal - Hub de juegos
├── views/
│   ├── gears-of-war.html        # Página de Gears of War
│   ├── halo.html                # Página de Halo (próximamente)
│   ├── resident-evil.html       # Página de Resident Evil (próximamente)
│   └── call-of-duty.html        # Página de Call of Duty (próximamente)
├── img/                          # Imágenes y recursos
├── styles/                       # Estilos CSS
│   ├── main.css                 # Estilos globales e index
│   └── gears-of-war.css         # Estilos específicos Gears of War
├── .gitignore                    # Configuración Git
├── .vscode/                      # Configuración VS Code
│   └── settings.json
└── README.md                     # Documentación
```

## 🚀 Características

✨ **Diseño Responsivo**
- Mobile-first approach
- Breakpoints para tablet (768px) y móvil (480px)
- Optimizado para todos los dispositivos

🎨 **Efectos Visuales**
- Animaciones suaves (glow, pulse, slide)
- Transiciones interactivas
- Drop shadows dinámicos en imágenes
- Efectos hover mejorados

♿ **Accesibilidad**
- Soporte para `prefers-reduced-motion`
- Soporte para `prefers-color-scheme`
- Atributos `alt` en todas las imágenes
- Navegación accesible por teclado

⚡ **Performance**
- CSS variables para fácil mantenimiento
- Estilos separados por componente
- Fuentes optimizadas de Google Fonts

## 📱 Responsive Breakpoints

```css
Escritorio:  > 768px   (estilos por defecto)
Tablet:      ≤ 768px   (redimensionamiento de texto e espacios)
Móvil:       ≤ 480px   (optimización extrema)
```
